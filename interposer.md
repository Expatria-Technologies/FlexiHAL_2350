For the A3 beta release of the FlexiHAL2350, an interposer is necesssary to use LinuxCNC via SPI to a Raspberry Pi 5.  If you purchased a beta board (before June5 2026) and did not receive an interposer, please contact Expatria via the webstore or on Discord and we will send you one.

The interposer doubles as a GPIO extender to allow use of an RPI5 with the OEM heatsink/cooler.  To install the interposer, make sure the white stripe is towards the RPI5 area of the board (pointed at the RP2350) as shown in the images below.
